# Highcharts вместо собственной отрисовки

Референс в скринкасте — это Highcharts: общий тултип, halo на точках, hover-состояния серий, скрытые независимые оси. Главное требование задания — точно повторить стиль и поведение, поэтому берём Highcharts. Своя отрисовка на SVG/d3 показала бы больше навыка, но добавила бы сотни строк hover-логики, и совпадение с оригиналом было бы хуже. Для коммерческого использования Highcharts нужна лицензия; для тестового задания это приемлемо.
